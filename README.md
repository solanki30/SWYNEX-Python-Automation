
# SWYNEX Python Automation Tool

## Project Name
Automatic File Organizer

## Description
This Python automation tool automatically organizes files
into separate folders based on their file extensions.

## Features
- Organizes image files.
- Separates PDF files.
- Organizes documents.
- Separates audio and video files.
- Moves unknown file types into an Others folder.
- Automatically creates folders.

## Technologies Used
- Python 3
- OS Module
- Shutil Module

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python file_organizer.py

5. Enter the folder path you want to organize.
